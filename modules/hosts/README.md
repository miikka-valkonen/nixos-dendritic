# Host Configurations

This directory contains configurations specific to individual machines (hosts).

## Hosts

| Host | Type | Details |
|------|------|---------|
| `laeppaeri` | Laptop | Intel CPU/iGPU, Nvidia 960MX dGPU (disabled), KDE Plasma 6 |
| `work` | WSL | NixOS-WSL, work-only dev tooling, no desktop |

## Directory Structure

Each host directory contains:

- `configuration.nix`: Defines `configurations.nixos.<name>` — sets user info, theming, and `hostModule.imports` listing NixOS modules.
- `home.nix`: Defines `configurations.homeManager.<name>` — sets `hostModule` with Home Manager imports.
- `hardware-configuration.nix`: Hardware-specific settings (generated by `nixos-generate-config`). Not present for WSL hosts.

## Host Options

Per-host options defined in `configuration.nix`:

| Option | Description |
|--------|-------------|
| `user.username` | Unix username |
| `user.email` | Email address (used in Git config) |
| `user.uid` | Optional UID override |
| `stateVersion` | NixOS state version |
| `wallpaper` | Path to wallpaper image |
| `base16Scheme` | Color scheme (`kanagawa-dragon`, `black-metal-mayhem`, `framer`) |
| `wsl` | Enable NixOS-WSL mode |

## Adding a New Host

1. Create a new directory here (e.g., `mkdir modules/hosts/<name>`)
2. Add `configuration.nix` and `home.nix` following the pattern of existing hosts
3. The dendritic architecture automatically discovers the new host — no registration needed
